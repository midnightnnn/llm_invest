Runs seven time-series models and summarizes each ticker with model-implied direction probability, vote counts, model_direction label, and compact model details. If tickers are omitted, it defaults to the self-discovered candidate basket plus current holdings. Use market_scope='us' for US-only forecast requests and market_scope='kr' for Korean-stock forecast requests; omit market_scope only when the user wants the agent/account's full configured market scope.
